Site baru satuan: buat station code dan profit center

Aturan dari sheet RULES. Station code EVCS: L.E. + kode provinsi 3 huruf + nomor 4 digit. BSS: B. + kode provinsi + nomor 5 digit. Nomor urut berjalan per provinsi dan naik terus. Profit center EVCS: 48 + kode lokasi provinsi (2 digit) + y + 0 + 4 digit nomor. BSS: 49 + kode lokasi + y + 5 digit nomor. y = 3 (operasi sendiri) atau 8 (kerja sama).

Kode untuk SAP

Isi nama site, jenis station, dan provinsi. Kode yang sudah ada dipakai, yang belum ada dibuatkan sesuai aturan RULES.
